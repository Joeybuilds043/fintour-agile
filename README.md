# Horizon Tourism

**Pakistan Digital Destination Discovery & Tourism Intelligence Prototype**

Horizon connects an editorial, experience-led visitor discovery journey with an emerging tourism intelligence and investment workspace.

## Run locally
Install requirements, then run: streamlit run app.py

## Workspaces
Discover Pakistan; destination guides; trip planner; explore map; destination intelligence; investment studio; data observatory.

## Data integrity
Weather forecasts are retrieved from Open-Meteo and cached temporarily. Destination photographs are retrieved from Wikimedia Commons and displayed with file-level attribution metadata where available. Destination editorial content and cluster coordinates require review. No hotel availability, live road safety, nationwide verified occupancy or visitor spending is claimed. Financial inputs are illustrative and user-editable.
