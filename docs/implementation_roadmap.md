# Implementation Roadmap

1. Foundation: repository audit, product blueprint, destination schema, evidence policy, tests and CI.
2. Visitor discovery: editorial homepage, experience taxonomy, ten destination clusters, licensed photography, destination guides and map.
3. Journey planning: itinerary builder, budget inputs, weather and source-grounded visitor concierge.
4. Destination intelligence: evidence ingestion, seasonality, accommodation, transport, spending and sustainability.
5. Investment studio: unit economics, operating costs, scenario analysis, sensitivity testing and local value.
6. Validation: mobile and desktop usability, data and licence review, academic demonstrator and deployment.

Each phase should be committed and tested separately. Do not label a feature live or verified until the source and refresh behaviour have been tested.
