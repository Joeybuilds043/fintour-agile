# Data Sources and Licensing

| Provider | Intended use | Considerations |
|---|---|---|
| Open-Meteo | Current conditions and forecasts | Free API for eligible non-commercial use; CC BY 4.0 attribution; commercial terms must be reviewed |
| Wikimedia Commons | Destination photography | Each file has its own licence and attribution requirements |
| Government of Gilgit-Baltistan | Published tourist inflows | Verify dates, coverage and units; partial-year data must not be annualised |
| Pakistan Tourism Development Corporation | Sector publications | Check publication date and geographic coverage |
| OpenStreetMap | Potential geographic data | ODbL attribution; public tile and geocoding services have separate usage policies |

## Image policy
Retrieve candidate files; read individual licence metadata; record creator, licence and source page; display attribution; do not infer licence from the platform name; replace files with missing or incompatible metadata.

## Weather policy
Forecasts are planning information, not road-safety, avalanche, flood or mountaineering advice. Display provider and retrieval time. If the service fails, show unavailable rather than stale data presented as current.

Free access is not equivalent to unrestricted commercial rights. Review provider terms before commercial deployment or high-volume use.
